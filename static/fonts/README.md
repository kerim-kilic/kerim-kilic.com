# Fonts

Self-hosted variable font (Latin subset), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). The site uses one typeface for everything:

- **Inter** by Rasmus Andersson, https://rsms.me/inter/, see `OFL-Inter.txt`

`OFL-Space-Grotesk.txt` stays because the "K" in `static/favicon.svg` is an outline taken from Space Grotesk Bold
(Florian Karsten, https://github.com/floriankarsten/space-grotesk). The font file itself is no longer served.

Obtained via Fontsource (https://fontsource.org). See also `THIRD-PARTY-NOTICES.md` in the repository root.
