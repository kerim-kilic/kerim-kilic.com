## Overview

The site you're reading is static HTML generated by Hugo and served from a private S3 bucket through CloudFront.

## Design

- **Private bucket, CloudFront origin access control.** The bucket blocks all public access; only this CloudFront distribution can read from it.
- **TLS via ACM**, validated with DNS records managed in Terraform.
- **CloudFront Function** for clean URLs and the `www` → apex redirect, so no server is needed.
- **Security headers** through a CloudFront response headers policy.
- **Keyless deployments.** GitHub Actions assumes a narrowly-scoped IAM role through OIDC, so there are no access keys to leak or rotate.
- **Everything as code.** Infrastructure lives in [`terraform/`](https://github.com/kerim-kilic/kerim-kilic.com/tree/main/terraform) in the same repository as the site.

## Why this approach

Static hosting is cheap, fast and has almost no operational surface to patch, which makes it a good fit for a personal site.
