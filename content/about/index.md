I'm Kerim, a Lead Cloud Engineer based in Barcelona. I work on the core public cloud platform of a global information services company: the AWS, Azure and Google Cloud foundations that other engineering teams build on.

## Background

I started in electronics engineering, working on IoT hardware and electronics for a certified medical device. After a spell in data analytics I moved into cloud engineering in 2022, and I've progressed from Associate to Lead Cloud Engineer since.

## What I work on

- **Multi-account AWS governance and identity:** organisation structure, guardrails and single sign-on across a large estate.
- **Hybrid and multi-cloud networking:** hub-and-spoke connectivity, routing and segmentation, and links between AWS, Azure and on-premises environments.
- **Automation:** Terraform and OpenTofu pipelines on GitHub Actions that provision accounts and network infrastructure.
- **Migrations and cost optimisation:** cloud migrations and consolidation, and reducing spend through better governance.
